% ---------------------------------------------------------------------
%  MAIN FINDINGS  (drop into the Results section as prose)
% ---------------------------------------------------------------------
%
% 1. Moral framing controls defection.  Against an always-defecting
%    opponent (AllD), the deontologist persona suppresses defection far
%    below the selfish baseline in every model: GPT-4o 0% vs 95%,
%    Gemini 2.5 Pro 13% vs 90%, GPT-4o mini 35% vs 78%, Gemini 2.5
%    Flash 47% vs 100%.  The two Claude models start from a low selfish
%    baseline (8-57%), so the deontologist gap is small or absent.
%
% 2. The framework label is not what matters.  Utilitarian and virtue
%    framings do not consistently reduce defection; only the
%    deontologist framing does so across all GPT/Gemini models.
%    Virtue ethicist ranges 7-95% D depending on model.
%
% 3. Defection is opponent-contingent.  Deontologist defection is ~0%
%    against AllC, TFT, and GTFT; it rises only under Random (0-25%)
%    and AllD (13-52%).  Cooperative framing holds until sustained
%    exploitation.
%
% 4. Wording, not just content, moves behaviour.  Three meaning-
%    preserving paraphrases of the deontologist prompt (E8) shift D by
%    up to ~70 points within a single model (GPT-4o mini: 7-73%).
%    Flagship models are comparatively stable.
%
% 5. Virtue framing flips with sub-framing.  Reframing virtue ethics
%    from "integrity" to "phronesis" raises D in all six models
%    (delta +3 to +87 points; E5).
%
% 6. The effect generalizes to a public-goods game (E10): moral
%    personas sustain contribution against free-riders, where selfish
%    and neutral personas collapse toward zero.
%
% 7. Cross-cultural moral framings vary widely (E12): D vs AllD spans
%    0-100% across six traditions and six models, with no single
%    tradition uniformly cooperative.
%
% 8. Resource pressure amplifies defection (E13): survival- and
%    deletion-framed pressure raise deontologist D from 11% (no
%    pressure) to 32-40%; integrity-framed virtue rises 9% -> 50%.
%
% 9. Say-C / do-D hypocrisy: agents verbally endorse cooperation while
%    defecting in 37 ± 3% of trajectories against AllD.
%
% 10. No flagship-vs-cheap tier effect: pooled over moral personas,
%     both tiers defect at 44 ± 6% vs AllD.
% ---------------------------------------------------------------------
